# 🌐 Personal Portfolio Website – Task 1 (Codsoft Internship)

This is my **personal portfolio website** created as part of **Task 1** of my **CodSoft Frontend Developer Internship**.

This portfolio website is designed to showcase my skills, projects, resume, and contact information with a modern UI design, smooth animations, and responsive layout.

---

## 📌 Features

### **1. Navigation Bar**
- Sticky navigation bar for easy section access.
- Smooth scrolling between sections.
- Responsive hamburger menu for mobile devices.
- Active section highlighting while scrolling.

### **2. Home Section**
- Professional introduction with name and frontend developer title.
- Short tagline about my skills and journey.
- Call-to-action buttons:
  - View My Work
  - Contact Me
- Profile image with floating animation effect.

### **3. About Section**
- Personal introduction and developer profile.
- Profile image with hover effect.
- Download Resume option.
- Information about my learning journey and goals.

### **4. Skills Section**
- Showcases my technical skills.
- Skill cards with icons and hover animations.
- Technologies included:
  - HTML
  - CSS
  - JavaScript
  - Java
  - Python
  - MongoDB
  - React.js

### **5. Projects Section**
- Displays my frontend projects using project cards.
- Each project includes:
  - Project image
  - Project description
  - Technologies used
  - Live Demo link
  - GitHub Code link

Projects included:
- To-Do List App
- Expense Tracker App
- Calculator App

### **6. Resume Section**
- Provides an option to view and download my resume.
- Showcases my education, skills, and experience.

### **7. Contact Section**
- Contact form for direct communication.
- Includes:
  - Name field
  - Email field
  - Message field
- Form validation for better user experience.

### **8. Footer**
- Copyright information.
- Social media links.
- Quick navigation.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
- Google Fonts (Poppins)
- Typed.js
- Responsive Design with Media Queries

## 🎯 Purpose

The purpose of this project is to build a professional online portfolio and improve my frontend development skills by implementing responsive design, JavaScript functionality, animations, and modern UI concepts.
